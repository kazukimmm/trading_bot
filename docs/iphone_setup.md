# iPhone でプッシュ通知を受け取る設定ガイド

このボットのダッシュボードを iPhone の「ホーム画面アプリ（PWA）」として追加すると、
重要なイベント（自動売却・ドローダウン警告・リバランス完了・改善提案）を
**プッシュ通知**で受け取れます。

---

## ⚠️ 重要な前提条件（必ず読んでください）

1. **iOS 16.4 以降が必須**
   Web Push は iOS 16.4 で初めて対応しました。これより古い iPhone では通知を受け取れません。
   （設定 → 一般 → 情報 → システムバージョン で確認）

2. **「ホーム画面に追加」したアプリからのみ通知が届く**
   Safari のタブで開いているだけでは通知は **届きません**。
   必ず後述の手順でホーム画面に追加してください。

3. **HTTPS でアクセスしている必要がある**
   プッシュ通知は安全な接続（HTTPS）でのみ動作します。
   - ✅ Railway などにデプロイした `https://...` の URL → 通知が使えます
   - ❌ 自宅 LAN の `http://192.168.x.x:8000`（HTTP）→ 通知は使えません
     （ダッシュボードの閲覧は可能ですが、通知許可ボタンは動きません）

   → **通知を使いたい場合は Railway へのデプロイ（`docs/railway_setup.md`）を先に済ませてください。**

## セットアップ手順

### STEP 1: サーバー側で VAPID キーを用意する（PC で 1 回だけ）

```bash
python scripts/generate_vapid_keys.py
```

出力された 3 行（`VAPID_PUBLIC_KEY` / `VAPID_PRIVATE_KEY` / `VAPID_EMAIL`）を
`.env` に貼り付けます（`VAPID_EMAIL` は自分のメールアドレスに変更）。

Railway を使う場合は、同じ 3 つを Railway の環境変数にも登録してください。

> 🔒 これらの鍵（特に `VAPID_PRIVATE_KEY`）は **絶対に Git にコミットしない** でください。
> `.env` は `.gitignore` 済みです。

### STEP 2: iPhone でダッシュボードを開く

Safari で、デプロイ済みのダッシュボード URL（例: `https://your-app.up.railway.app`）を開きます。

### STEP 3: ホーム画面に追加する

1. 画面下の **共有ボタン（□に↑）** をタップ
2. メニューから **「ホーム画面に追加」** をタップ
3. 「追加」をタップ

→ ホーム画面に「TradingBot」アイコン（緑の上昇矢印）が追加されます。

### STEP 4: ホーム画面のアイコンからアプリを起動して通知を許可する

1. ホーム画面の **TradingBot アイコン** をタップして起動
   （Safari のタブからではなく、必ずアイコンから起動）
2. 上部に表示される **「🔔 重要なアラートを受け取りますか？」** バナーの
   **「許可する」** をタップ
3. iOS の確認ダイアログで **「許可」** を選択
4. 「✅ 通知を有効にしました。」と表示されれば完了

## 動作テスト

PC 側で以下を実行すると、登録済みの iPhone にテスト通知が届きます。

```bash
# 通常の通知
python scripts/test_push_notification.py

# タイトル・本文・緊急度を指定
python scripts/test_push_notification.py "🔴 テスト警告" "これは高緊急度のテストです" high
```

- 「登録済みデバイス数: 1」以上になっていれば購読は成功しています。
- 0 の場合は STEP 4 をやり直してください。

---

## 通知の種類

| 緊急度 | アイコン | 例 | バイブ |
|--------|---------|----|--------|
| 🔴 high   | 強調表示・自動で消えない | 自動売却の実行 / ドローダウン警告 | 強め |
| 🟡 medium | 通常 | （現状は high/normal を使用） | 通常 |
| 🟢 normal | 通常 | リバランス完了 / 改善提案あり | 通常 |

通知設計方針:
- 🔴 **絶対通知**: 自動売却の実行、ドローダウン 10% 超の警告
- 🟡 **基本通知**: リバランス完了、戦略改善提案
- （月次レポートは Slack 側で送信）

---

## うまくいかないときは

| 症状 | 原因 / 対処 |
|------|------------|
| 「許可する」ボタンを押しても何も起きない | HTTP で開いている。HTTPS（Railway）でアクセスする |
| 通知許可バナーが出ない | すでに許可済み、または iOS 16.4 未満。バージョンを確認 |
| テスト通知が届かない（デバイス数 0） | ホーム画面アイコンから起動して許可し直す |
| 一度許可したが届かなくなった | アプリを削除→再追加で購読し直す（古い購読は自動削除されます） |
| `VAPID キーが未設定です` と表示 | STEP 1 を実施し `.env`／Railway 環境変数に登録 |

---

## 補足

- 通知はあくまで「お知らせ」です。**設定変更や売買は人間が最終判断** します
  （AI 改善提案も自動では何も変更しません）。
- 購読情報は `logs/push_subscriptions.json` にローカル保存されます。
- 無効になった購読（アプリ削除など）は送信時に自動で削除されます。
