米国株 自動売買ボット — プロダクト全体ワークフロー

戦略：デュアルモメンタム（負けにくさ重視・元本保全型）

データ／処理 リスクオン（投資） リスクオフ（退避・警告） 記録・通知 ユーザー／AI
① 自動スケジュール（24時間ボットが見張る）

main.py の APScheduler が米国東部時間で4つのジョブを自動実行します。 人は何もしなくてOK。

タイミングジョブ内容
毎月 第1営業日
09:35 ET		 リバランス 戦略を計算して保有銘柄を入れ替える（中心の処理）
毎営業日
15:55 ET		 ドローダウン監視 含み損が大きすぎたら自動で全部売って安全資産へ退避
毎月 最終営業日
16:10 ET		 月次レポート 今月の成績・保有・損益をまとめてSlackへ送信
毎月 最終営業日
20:00 ET		 AI戦略レビュー 成績を点検し、改善案を理由付きで生成（自動変更はしない）
② 月次リバランスの流れ（ボットの頭脳）

📥 1. データ取得 DataFetcher

監視リスト（SPY・QQQ・各ETF等）の過去2年分の終値を取得。 Alpacaで「相場が開いているか」も確認。休場なら何もしない。

▼

🛡️ 2. まずドローダウン判定 risk_manager

ピーク資産から 15% 以上下げていたら、戦略計算をスキップして 即「リスクオフ」。安全資産 BIL へ全額退避する。

▼

🧠 3. デュアルモメンタム判定 strategy

2つの条件で「攻める／守る」を決定：

🟢 絶対モメンタム OK

基準（SPY）の9ヶ月リターンがプラス → 相対モメンタム上位 3銘柄 を選んで投資（リスクオン）。

🔴 絶対モメンタム NG

SPYの9ヶ月リターンがマイナス → 株は持たず 安全資産 BIL へ退避（リスクオフ）。

▼

⚖️ 4. ポジションサイズ調整 risk_manager

1銘柄あたりの上限（max_position_size）を超えないよう配分。 注文額が資金比率を超えていないか validate_order で検証。

▼

💸 5. 注文執行 OrderExecutor → Alpaca

いったん全ポジションを決済 → 目標の銘柄を新規購入。 現在は ペーパー取引（仮想資金 $100k） で稼働中。

③ 記録・通知（毎回の判断を残す）
リバランス完了後、自動で並行実行 ＋ デグレード安全設計

📝 判断ログ

「なぜこの銘柄を買ったか／退避したか」を理由付きで logs/*.json に保存。

🔔 通知

Slack ＋ iPhoneへ Web Push。リバランス完了、DD警告、 自動売却、戦略提案などを送信。

※ ログ・通知は try/except で保護。失敗しても取引本体は絶対に止めない設計。

④ 見える化（あなたの確認窓口）

📱 モバイルダッシュボード FastAPI + PWA

dashboard/ が JSON API を配信し、iPhoneのホーム画面アプリで確認可能：

総資産（$ と ¥ 併記） 元本・損益 保有銘柄 資産推移グラフ 直近の売買理由 為替レート AI戦略提案

▼

🧑‍💼 5. 最終判断はあなた 人間が決める

AIは改善案を提案するだけ。設定（config/settings.py）の 変更は人間が手動で行う。ボットが勝手に戦略を変えることはない。

⑤ 別ライン：検証・改善（運用と並行）
